# Prova 2026.1

Prova da disciplina Iniciação à Computação.

## Para começar

1. Faça um fork deste repositório na sua conta do GitHub.
2. Crie um Codespace ([instruções](CODESPACES.md)).
3. No terminal, execute `chmod +x init.sh` para tornar o script executável e, em seguida, rode `./init.sh`. Esse processo instala tudo o que você precisa para começar o trabalho.
4. Dê uma olhada em `src/playground.ipynb`, pois os exemplos nele são úteis.
5. No arquivo `docs/report.pdf` estão as instruções dos problemas a serem resolvidos.
6. Depois de editar `src/main.py` para obter os resultados desejados, registre esses resultados em `docs/report.typ`.
7. Numa nova sessão do terminal (símbolo $+$ no terminal), execute `typst watch --root . docs/report.typ docs/report.pdf` para atualizar seu PDF, e deixe o terminal rodando enquanto você trabalha.
8. Finalmente, baixe `docs/report.pdf` para enviar pelo SIGAA.
